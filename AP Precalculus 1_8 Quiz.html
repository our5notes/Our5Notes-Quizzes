If both the numerator and denominator of a rational function equal zero at the same x-value, that x-value is:

B. A common zero in both numerator and denominator indicates a removable discontinuity (hole).

Medium

Using the graph shown of f(x)=(x−2)(x+1)/(x−4), the zeros are:

B. The numerator's factors give zeros at x=2 and x=−1; x=4 is a vertical asymptote, not a zero.

Hard

For h(x)=(x²−9)/(x−3), a student sets the numerator equal to zero and finds x=±3, concluding both are zeros. Why is this reasoning incomplete?

B. Checking the denominator reveals x=3 is a hole, leaving x=−3 as the only genuine zero.

Free Response

Use the graph of f(x) = (x − 2)(x + 1)/(x − 4) shown above.

(a) Identify the zeros of f shown on the graph.
Sample response: x=2 and x=−1.
(b) Find the zeros of g(x)=(x²−16)/(x+7) algebraically.
Sample response: x²−16=0 → x=±4. Checking the denominator at x=±4: nonzero, so both are valid zeros.
(c) Find the zeros of h(x)=(x²−9)/(x−3) algebraically, being careful to check for any values that are actually holes rather than zeros.
Sample response: Numerator zero at x=±3. At x=3, the denominator is ALSO zero (since x−3 is a common factor) — this is a hole, not a zero. The simplified function is h(x)=x+3 for x≠3, so the only true zero is at x=−3.
