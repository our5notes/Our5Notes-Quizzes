If (3,7) is a point on f, which point must be on f⁻¹?

B. Inverse functions swap the input and output, so (3,7) becomes (7,3).

Hard

A student finds the inverse of f(x)=x²+4 by swapping x and y to get x=y²+4, then solving to get y=±√(x−4). They claim this gives "the" inverse function. What is the issue?

B. A ± expression produces two outputs per input, violating the definition of a function — domain restriction is required first.

Free Response

Let f(x) = 3x − 5.

(a) Find f⁻¹(x) algebraically.
Sample response: y=3x−5 → x=3y−5 → y=(x+5)/3. f⁻¹(x) = (x+5)/3.
(b) Verify your answer by checking that f(f⁻¹(x))=x.
Sample response: f(f⁻¹(x)) = 3[(x+5)/3]−5 = (x+5)−5 = x ✓.
(c) The function g(x)=x²−2 is not invertible on all real numbers. Describe a domain restriction that would make it invertible, and explain why.
Sample response: Restricting the domain to x≥0 (or x≤0) makes g invertible, since this eliminates the horizontal-line-test failure caused by g(x) producing the same output for both a positive and negative x-value.
