Use the graphs shown above (standard scale vs. semi-log scale).

(a) Explain why plotting log(y) instead of y against x transforms exponential data into a straight line.
Sample response: Since y=a·bˣ implies log(y)=log(a)+x·log(b), this is a linear equation in x and log(y), so plotting log(y) against x produces a straight line for true exponential data.
(b) A semi-log plot has the line log(y)=0.2x+0.5. Find the original exponential function y=a·bˣ.
Sample response: log(a)=0.5 → a=10^0.5≈3.16. log(b)=0.2 → b=10^0.2≈1.585. y≈3.16(1.585)ˣ.
(c) Explain how a semi-log plot could be used to determine whether a real-world data set is better modeled by an exponential function or some other type of function.
Sample response: If the data forms a straight line on a semi-log plot, this confirms an exponential model is appropriate; if the data instead shows curvature, this suggests the data does NOT follow a true exponential pattern, and a different model should be considered.
