Free Response FRQ

Refer to the diagram shown above.

(a) Identify what the central branch point in the diagram shown represents.
Sample response: The central branch point in the diagram represents the common ancestor of the species shown.
(b) Explain why the near-universality of the genetic code is considered strong evidence for common ancestry.
Sample response: If life had originated multiple independent times, there would be no particular reason for different lineages to evolve the exact same genetic code; the fact that nearly all organisms share this code strongly suggests it originated once, in a single common ancestor.
(c) Explain how comparing DNA sequences of two species can help estimate how long ago they diverged.
Sample response: DNA sequences accumulate mutations at a roughly predictable rate over time, so by comparing the number of sequence differences between two species, scientists can estimate how much time has passed since they last shared a common ancestor.
