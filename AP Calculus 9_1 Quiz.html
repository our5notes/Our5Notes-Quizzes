Use the parametric curve x(t)=t²−1, y(t)=t³−3t shown above.

(a) Find dy/dx in terms of t.
Sample response: dx/dt=2t. dy/dt=3t²-3. dy/dx = (3t²-3)/(2t).
(b) Evaluate dy/dx at t=2.
Sample response: At t=2: (3(4)-3)/(4) = 9/4.
(c) Find all values of t where the curve has a horizontal tangent, and all values where it has a vertical tangent.
Sample response: Horizontal tangent: set dy/dt=3t²-3=0 → t=±1 (checking dx/dt=2t≠0 at each, which holds for both). Vertical tangent: set dx/dt=2t=0 → t=0 (checking dy/dt=3(0)²-3=-3≠0 ✓).
