Use the graph of the sinusoidal function shown above.

(a) Identify the amplitude, midline, and period from the graph.
Sample response: Amplitude = 3, midline y=2, period = 4π.
(b) Write a possible equation for the function in the form f(x)=a·sin(b(x−c))+d.
Sample response: f(x) = 3sin(0.5x) + 2.
(c) A different function has amplitude 2, period 3π, midline y=−4, and phase shift π. Write its equation using cosine.
Sample response: b = 2π/(3π) = 2/3. f(x) = 2cos((2/3)(x−π)) − 4.
