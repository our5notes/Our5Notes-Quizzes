Let f(x) = x³ − 3x² − 9x + 2.

(a) Find f'(x) and all critical points.
Sample response: f'(x)=3x²-6x-9=3(x-3)(x+1). Critical points: x=-1 and x=3.
(b) Use the Second Derivative Test to classify each critical point.
Sample response: f''(x)=6x-6. f''(-1)=-12<0 → local max at x=-1. f''(3)=12>0 → local min at x=3.
(c) Let g(x)=x⁴-4x³. At the critical point x=0 (where g'(0)=0), show the Second Derivative Test is inconclusive, and state what should be done instead.
Sample response: g'(x)=4x³-12x². g''(x)=12x²-24x. g''(0)=0, so the Second Derivative Test is inconclusive at x=0; the First Derivative Test must be used instead.
