Free Response

The graph of y=q(x) shows a tangent line at x=2 passing through (2,2) and (4,6).

(a) Using the tangent line, estimate q'(2). Show the rise and run you used.
Sample response: Rise/run = (6-2)/(4-2) = 4/2 = 2. q'(2) ≈ 2.
(b) A table gives f(3)=8.1, f(3.1)=8.7, f(2.9)=7.4. Estimate f'(3) using the symmetric difference quotient.
Sample response: [f(3.1)-f(2.9)]/0.2 = (8.7-7.4)/0.2 = 1.3/0.2 = 6.5.
(c) Explain why a symmetric difference quotient generally gives a more accurate derivative estimate than a one-sided difference quotient of the same step size.
Sample response: A symmetric estimate balances the curvature of the function on both sides of the point, so errors from the function bending away from linear behavior partially cancel, whereas a one-sided estimate only reflects behavior on one side and can be skewed by curvature in that direction.
