A data set shows that as an input variable doubles repeatedly (multiplicatively), the output increases by the same constant amount each time (additively). What type of model does this pattern suggest, and why?

B. Constant additive output change paired with multiplicative input change is the hallmark of a logarithmic relationship.

Free Response
(a) The pH of a solution is given by pH=−log[H⁺]. Find the pH of a solution with [H⁺]=4×10⁻³.
Sample response: pH = −log(4×10⁻³) = −(log4+log(10⁻³)) = −(0.602−3) = 2.398.
(b) Two earthquakes have magnitudes 4.5 and 6.5 on the Richter scale. How many times more intense is the larger earthquake?
Sample response: Difference = 2, so 10² = 100 times more intense.
(c) MODEL: Table shows sound intensity vs decibels: Intensity(W/m²)=10⁻¹²,10⁻¹⁰,10⁻⁸; Decibels=0,20,40. Explain why a logarithmic model is appropriate for this data.
Sample response: As intensity increases multiplicatively (×100 each step), decibels increase by a constant additive amount (20 each step) — this is the defining pattern of a logarithmic relationship, confirming the model is appropriate.
