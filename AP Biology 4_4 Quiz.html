Free Response FRQ

Refer to the diagrams shown above.

(a) Identify which loop in the diagram represents negative feedback.
Sample response: The loop showing the response reversing the original stimulus (such as insulin lowering glucose) represents negative feedback.
(b) Explain why negative feedback is more common than positive feedback in maintaining everyday physiological stability.
Sample response: Negative feedback works to counteract changes and return a system to a stable set point, which is essential for maintaining homeostasis under everyday, ongoing conditions; positive feedback instead drives a system away from its starting point, which is useful only in limited situations requiring rapid completion.
(c) Explain why positive feedback is well-suited to the process of childbirth, referencing the diagram shown.
Sample response: During childbirth, contractions trigger oxytocin release, which intensifies contractions further, creating a rapidly escalating response; this positive feedback loop is well-suited to childbirth because the process needs to be driven quickly to completion rather than stabilized, ensuring birth occurs efficiently once begun.
